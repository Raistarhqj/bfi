# 光的时间切片 · BFI 时序实验室

A1 光谱实验台的最终版：一个可直接打开的单页科普仿真站。零依赖 Canvas 2D 时序仿真 + 可拖拽的 3D 显示层拆解 + 可拖动的 16.7ms 帧时间轴。

版式不是逐页幻灯片：首页是全屏仿真背景 + 底部控制台；第二屏是全幅 3D 拆解台；时间轴、两种黑窗、代价、六种产品分别使用横向带、交错双栏、错位三段和全幅产品展台。

滚动不是单纯平动：标题用 clip-path 扫入，3D 台用幕布落下，产品卡片带 3D 倾斜与模糊退场，首页有缩放/模糊视差，右侧有章节进度轨，顶部有滚动进度线。

## 直接打开

双击 `index.html` 即可，不需要构建、不需要后端。也可以：

```powershell
python -m http.server 4173 --bind 0.0.0.0
# 本机：http://127.0.0.1:4173/index.html
# 同一 Wi-Fi：http://<本机局域网IP>:4173/index.html
```

## 发布成公网链接

`dist/` 是可直接部署的纯静态目录，`dist.zip` 是对应压缩包。

- **最快**：打开 https://app.netlify.com/drop，把 `dist` 文件夹拖进去，得到 `https://xxx.netlify.app`。
- **GitHub Pages**：新建仓库，上传 `dist` 里的**内容**（不是 `dist` 文件夹、不是 zip），Settings → Pages → Deploy from branch，目录选 `/ (root)`。
- **Vercel / Cloudflare Pages**：新建静态项目，构建命令留空，输出目录填 `dist`。

GitHub Pages 上“页面残缺、没有 3D / 音乐”时，先看 [GITHUB-PAGES.md](GITHUB-PAGES.md)：最常见原因是只上传了 `index.html`，没有上传 `sim/` 和 `audio/`。`3D 不是模型文件`，而是 `sim/apps3d.js` 实时绘制的；音乐是 `audio/nocturnal.mp3`。

部署后把得到的 `https://...` 链接发给别人即可。不要发 `127.0.0.1` 或 `192.168.x.x`，这两个只在你的本机/同一 Wi-Fi 内有效。

## 交互清单

**实验台**
- 模式：普通显示 / 全局 BFI / 扫描 BFI
- 预设：60Hz 普通、240Hz 全局、240Hz 扫描、360Hz 扫描
- 旋钮：刷新率 60–360Hz、液晶响应 1–16ms、分区 2–16
- 推子：背光占空比 10–100%
- 指标：帧周期、拖影长度、平均亮度、频闪风险
- 暂停 / 继续

**3D 拆解**
- 拖动旋转；滚轮缩放
- 拆解距离推子：把背光、扩散、液晶、前玻璃拉开
- 三个层开关：分区背光 / 液晶层 / 前玻璃
- 自动旋转 / 重置视角

**帧时间轴**
- 拖动 playhead 或方向键读取 0–16.7ms
- 实时判断当前落在“液晶尚未翻转 / 翻转中间 / 基本稳定”

**六种产品的 3D 展台**
- AR 眼镜 / 车载 HUD / 医疗内窥 / 航空座舱 / 工业检测 / 赛事回放
- 左侧六个实时 3D 缩略图，选中后右侧大图可拖动旋转、滚轮缩放
- 产品使用逐面光照、渐变高光、金属/玻璃/屏幕材质与局部发光边缘
- 产品形态为程序化示意，不使用品牌资产

**声音**
- 背景音乐：`audio/nocturnal.mp3`，循环，音量约 12%
- 首次点击页面或直接点右上角 `SOUND / READY` 开启；可随时静音
- 旋钮、推子、时间轴拖动和按钮切换都有 Web Audio 合成音效，音量高于背景音乐

所有指标为**教学示意**，不是产品实测。扫描 BFI 不消灭总暗时间，也不无条件提升亮度。

## 设计说明

- 深墨黑、光谱色、细网格、测量视窗；辉光只放在边缘、旋钮弧、3D 背光条和实时扫描线上。
- 3D 不是装饰：它把一帧拆成四层，让“暗带发生在背光层”变成可绕看的结构。
- 桌面与 375px 宽度均检查：无横向溢出、控制台无报错、旋钮/推子/3D/时间轴均可操作。
